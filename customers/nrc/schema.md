# NRC 태스크 스키마

`templates/task-schema.md` 를 NRC 에 적용한 것. 플랫폼 = Multica, DB = Baserow.

## 1. 분류 라벨

```
경제인문사회연구회   항상 붙음
내부업무            일반 업무          → Baserow General Tasks
단순처리업무         1시간 내 SR        → Baserow SR Tasks
(없음)              일반 SR            → Baserow SR Tasks
상위업무 / 하위업무   계층 표시. SR·일반 모두
```

적재 규칙: **`내부업무` 있으면 General Tasks, 없으면 SR Tasks.**

단순처리 판단 기준: NGS 계정 생성, ACG 규칙 추가, IP 차단, 권한 추가처럼 **접수 후 1시간 안에 끝나는 정형 작업**.

## 2. 계층

- 하위 이슈는 플랫폼의 부모 연결로 만든다.
- 하위 이슈 본문 첫 줄에 `상위: <상위 제목>`.
- DB 에는 각각 별개 행. 비고 첫 줄로 관계가 남는다.

## 3. 상태 매핑

| Baserow | Multica | 표시 |
|---|---|---|
| To do | todo | 할일 |
| Working | in_progress | 진행중 |
| Pending | in_review | 리뷰중 |
| Done | done | 완료 |
| On hold | blocked | 보류 |

## 4. 기관

`orgs.md` 참조. 제목 접두사 `[약칭]` + 플랫폼 속성 `NRC 기관`(select) 둘 다.

## 5. 필수 / 선택

| 항목 | SR | 일반 |
|---|---|---|
| 제목 | 필수 | 필수 |
| 기관 | 필수 | 선택 |
| 분류 라벨 | 자동 | `내부업무` 자동 |
| 담당자 | 선택 | 선택 |
| 시작일 | 필수 (기본 = 오늘) | 필수 (기본 = 오늘) |
| 마감일 | 선택 | 선택 |
| 본문 | 필수 (`templates/issue-format.md`) | 필수 |

필수가 빠지면 에이전트는 **묻는다**. 추측으로 채우지 않는다.

## 6. 날짜

- 시작일: 말 없으면 오늘.
- 마감일: 정해진 게 없으면 비움.
- 종료일: 완료 처리 시 자동. DB 종료일 값이 있으면 그 값, 없으면 당일.

## 7. 담당자

`<담당자 매핑은 플랫폼 내 스킬에서>` — 이 저장소에는 두지 않는다.

## 8. 적재 규칙

**DB → 플랫폼** (Freshdesk 티켓 경로)
- DB 행에 제목이 채워지면 이슈 생성. 담당자·상태·본문·날짜 변경분만 갱신. metadata `baserow_row_id` 로 대응.

**플랫폼 → DB** (에이전트 생성 경로)
- 이슈가 생기면 라벨로 테이블 결정 → 행 생성. 이후 상태·담당자·본문·날짜 변경도 반영.
- 순환 방지: 내가 쓴 값과 같은 값이 돌아오면 무시. metadata `source` 로 출처 구분.
