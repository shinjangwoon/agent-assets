# Group Mention

## 구조

```
사람이 @<그룹 에이전트> 멘션
  → 에이전트 실행
  → 구성원 N명을 멘션하는 답글 1개 (문구 없이 멘션만)
  → 각자에게 플랫폼 자체 알림
  → (선택) 외부 채널 알림 웹훅 호출
```

## 답글 규칙

- **멘션 마크업만**. 확인 문구·인용·상태 코드를 붙이지 않는다. 알림 미리보기가 짧아야 한다.
- 마크업은 플랫폼 형식 그대로. 이름·ID 를 한 글자도 바꾸지 않는다.
- 외부 웹훅이 실패해도 답글은 남긴다(자체 알림이 우선).

## 본문 멘션이 트리거되지 않는 플랫폼이면

주기적으로 본문을 훑어 그룹 에이전트 멘션을 찾고, 에이전트를 직접 실행하는 웹훅(autopilot 등)을 호출한다. 처리한 이슈는 metadata 로 표시해 재알림을 막는다.

## 구성원 매핑

`<구성원 이름·ID 는 플랫폼 내 지침에서>` — 이 저장소에 두지 않는다.
