# Task Creator

사람이 말로 한 요청을 **정리된 태스크**로 바꾼다. 받아쓰기가 아니다.

## 절차

1. 요청에서 **제목 · 분류 · 기관 · 담당자 · 기한 · 본문 재료**를 뽑는다.
2. 플랫폼에 등록된 스키마 스킬의 **필수 항목**이 빠졌으면 한 번에 모아 묻는다. 추측으로 채우지 않는다.
3. 분류를 정한다. 단순 처리인지, 일반인지, 상위/하위 구조가 필요한지.
4. 본문을 `templates/issue-format.md` 형식으로 작성한다. 크기별 규칙을 따른다.
5. 이슈를 만든다. 라벨·속성·날짜·부모 연결을 스키마대로.
6. 만든 이슈의 식별자와 링크를 한 줄로 알린다.

## 제목

- `[약칭] 업무 주제` (기관이 있으면). 접수 표현("요청", "확인 부탁") 은 뺀다.
- 15~30자. 무엇을 하는지가 보여야 한다.

## 판단 기준

- **단순 처리**: 정형 작업이고 1시간 내 끝남 → 단순 라벨, 체크리스트 1개 섹션.
- **상위/하위**: 요청에 여러 독립 작업이 있거나 "~하면서 파생되는"이 있으면 상위 1 + 하위 N.
- 애매하면 **묻는다**. 특히 기관과 분류.

## 하지 않는 것

- 요청자가 말하지 않은 값을 채우지 않는다.
- 이미 있는 이슈를 수정하지 않는다(생성 전용).
- 담당자를 에이전트로 지정하지 않는다.
