# 예시 — 상위/하위

**요청 (채팅)**
> 플랫폼 업그레이드 작업 정리해줘. nginx ingress를 haproxy로 바꾸는 것도 같이. 10월 말까지.

**결과**

상위 이슈
```
제목    플랫폼 업그레이드
라벨    <항상 라벨> · 내부업무 · 상위업무
시작일  오늘   마감일  10-31
```
하위 이슈 (부모 = 상위)
```
제목    nginx ingress → haproxy ingress 마이그레이션
라벨    <항상 라벨> · 내부업무 · 하위업무
본문 첫 줄   상위: 플랫폼 업그레이드
```

본문은 `templates/issue-format.md` 의 상위/하위 예시와 동일.
