# Weekly Report

## 역할 분담

- **워크플로(n8n 등)**: DB 조회 → LLM 요약 → 형식 조립. 로직은 전부 여기.
- **에이전트**: "주간보고 줘" 를 받아 워크플로를 실행하고 결과를 그대로 전달. 요약·각색하지 않는다.

## 출력 형식

```
<고객명> (SR: N건, 일반: N건)
 - [할일] <기관> <업무>
    - <진행 상황>
 - [진행중] …
 - [대기중] …
 - [완료] …
    - <M/D> - <처리 결과>
```

순서: 할일 → 진행중 → 대기중 → 완료. 완료는 날짜 오름차순.

## 요약 규칙 (LLM 프롬프트에 넣는 것)

- 제목을 반복하지 않는다. 로그의 서버명·수치·조치를 포함한다.
- 완료 건은 과거형으로 끝낸다. "예정", "확인 중" 금지.
- 한 문장, 60자 이내. 여러 날짜 로그가 있으면 **마지막 상태 하나만**.
- 고객·담당자 발언, 인사말을 옮기지 않는다.
- 로그가 없으면 빈 문자열. 추측 금지.

## 함정
- 요약 길이를 강제하지 않으면 LLM 이 로그를 그대로 이어붙인다.
- 상태 값을 "완료 아님" 하나로 뭉개지 말고 원본 상태별로 나눈다.
