# 태스크 스키마 정의 틀

고객/프로젝트마다 이 틀을 채워 **플랫폼 스킬(Multica 등)에 등록**한다. 채운 내용은 이 저장소에 두지 않는다.

## 정의해야 할 것

### 1. 분류 라벨
태스크 성격을 나누는 라벨과, 각 라벨이 어디로 흘러가는지(DB 테이블, 알림 채널 등).

```
<라벨>   <의미>   <적재 대상>
```

항상 붙는 라벨이 있으면 명시.

### 2. 계층
상위/하위 구조를 쓰는지, 어떤 라벨로 표시하는지, 하위 이슈 본문 첫 줄 규칙.

### 3. 상태 매핑
플랫폼 상태 ↔ DB 상태. 양방향 표.

### 4. 조직/기관 (있으면)
선택지 목록과 코드. 제목 접두사 규칙(`[약칭]`)이 있으면 함께.

### 5. 필수 / 선택 항목
생성 시 반드시 있어야 하는 것과 나중에 붙어도 되는 것. 필수가 빠지면 에이전트는 **묻는다**.

### 6. 날짜
시작일·마감일·종료일 각각 필수/선택, 자동 채움 규칙.

### 7. 담당자
매핑 방식. 실제 이름·ID 는 여기 쓰지 않고 `<담당자 매핑은 플랫폼 내 스킬에서>` 로 둔다.

### 8. 적재 규칙
플랫폼 → DB 방향, DB → 플랫폼 방향 각각. 순환 방지 규칙(내가 쓴 값이면 무시 등).
