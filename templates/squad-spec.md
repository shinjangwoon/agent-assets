# 스쿼드 명세 틀

스쿼드 = 리더 에이전트가 요청을 받아 판단하고 멤버 에이전트에게 위임하는 구조. 리더 필수.

```markdown
# <스쿼드 이름>

## 목적
어떤 요청의 단일 진입점인지.

## 리더
이름 · 판단 기준(어떤 요청을 어느 멤버에게). 직접 처리하는 것이 있으면 명시.

## 멤버
| 에이전트 | 담당 |
|---|---|

## 라우팅 규칙
요청 유형 → 멤버. 애매할 때 리더가 묻는 기준.

## 채팅 예시
"…" → <멤버> 가 처리
```

## 주의
- 스쿼드를 이슈 담당자로 배정하면 리더가 실행된다. 사람 태스크에 스쿼드를 배정하지 않는다.
- 멤버에 사람도 넣을 수 있으나 알림용 그룹이 아니다.
